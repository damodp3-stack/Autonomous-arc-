# Development Rules

Rules for future AI agents and developers working on Autonomous Arc.

- Inspect existing code before changing it.
- Read "docs/" before starting major tasks.
- Read "PROJECT_STATE.md" first.
- Never rebuild working functionality unnecessarily.
- Make incremental changes.
- Do not delete working features without justification.
- Never hard-code secrets.
- Never commit API keys.
- Never fake implemented functionality.
- Test changes.
- Fix errors caused by changes.
- Update PROJECT_STATE.md after meaningful changes.
- Update CHANGELOG.md after meaningful changes.
- Update architecture documentation when architecture changes.
- Prefer reversible changes.
- Ask the user only when an important product/destructive decision is ambiguous.
- Actual source code and build state override outdated documentation.
